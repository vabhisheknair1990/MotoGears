# MotoGears Frontend (Angular 22)

Storefront (`/`) and admin console (`/admin`). See the [root README](../README.md) for the full guide.

```bash
npm install
ng serve        # http://localhost:4200 (expects the API at http://localhost:8000/api/v1)
ng test         # unit tests (Vitest)
ng build        # production build in dist/automotive-shop-frontend/browser
```
