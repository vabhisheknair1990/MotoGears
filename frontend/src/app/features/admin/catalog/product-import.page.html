Good to know

  • SKU is the key. An existing SKU updates that product; a new SKU creates one. Never change a product's SKU in the file.
  • Empty cells keep the current value when updating. Type CLEAR to erase an optional field.
  • Use the dropdowns for category, brand and vehicles — every valid value is on the Lists sheet.
  • Compatibility, Variants and FAQs link to products by SKU. If a SKU appears there, that product's list is replaced by the file.
  • Stock on hand sets the stock count; every change is logged in Inventory.
  • Images: paste public links separated by |. They download in the background; the first is the main photo.
  • Each product is saved completely or not at all — one bad row never breaks the others.
